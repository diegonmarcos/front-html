# front-html

Public hub of the owner's HTML front ends.

- `diegonmarcos.github.io/` : git submodule, the GitHub Pages site repo.
- `profile/` : git submodule, `diegonmarcos/diegonmarcos` (the GitHub profile README).
- `pages.json` : every public repo of the owner that publishes GitHub Pages (`repo`, `url`, `source`, `public`).
  Generated by `scripts/gen-pages.py` from the GitHub API, never edited by hand. Only public Pages URLs are listed.
- `.github/workflows/pages-drift.yml` : daily (and on push) regenerates `pages.json` and fails when it differs from the committed file.

## Use

    git clone --recurse-submodules https://github.com/diegonmarcos/front-html
    GH_TOKEN=... python3 scripts/gen-pages.py          # rewrite pages.json
    GH_TOKEN=... python3 scripts/gen-pages.py --check  # exit 1 on drift

## Consumers

Cloud Browser (Favourites > GH Pages) reads
`https://raw.githubusercontent.com/diegonmarcos/front-html/main/pages.json` at runtime and keeps the last good copy as a cache.
